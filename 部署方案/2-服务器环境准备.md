## 服务器选购

### 1. 推荐配置

**入门配置（适合测试/小流量）：**
- CPU：2核
- 内存：4GB
- 硬盘：40GB SSD
- 带宽：3Mbps

- 硬盘：100GB SSD
- 带宽：5Mbps

**推荐：CentOS 7.9 或 Ubuntu 20.04 LTS**

## 连接服务器

### 1. 获取服务器信息

购买服务器后，记录以下信息：
```
公网IP：123.456.789.100
用户名：root
密码：your_password
```

### 2. 使用 SSH 连接

**Windows 用户（使用 PowerShell 或 CMD）：**
```bash
ssh root@123.456.789.100
```

**Mac/Linux 用户：**
```bash
ssh root@123.456.789.100
```

**首次连接提示：**
```
The authenticity of host '123.456.789.100' can't be established.
Are you sure you want to continue connecting (yes/no)?
```
输入 `yes` 并回车。

### 3. 修改 root 密码（可选）

```bash
passwd
```

### 4. 创建普通用户（推荐）

```bash
# 创建用户
useradd -m -s /bin/bash deploy

# 设置密码
passwd deploy

# 添加 sudo 权限
echo "deploy ALL=(ALL) NOPASSWD:ALL" >> /etc/sudoers

# 切换到普通用户
su - deploy
```

## 安装 JDK 17

### 方式1：使用 yum 安装（推荐）

```bash
# 更新系统
sudo yum update -y

# 安装 JDK 17
sudo yum install -y java-17-openjdk java-17-openjdk-devel

# 验证安装
java -version
```

**预期输出：**
```
openjdk version "17.0.x" 2024-xx-xx
OpenJDK Runtime Environment (build 17.0.x+x)
OpenJDK 64-Bit Server VM (build 17.0.x+x, mixed mode, sharing)
```

### 方式2：手动下载安装

```bash
# 下载 JDK 17
cd /opt
sudo wget https://download.oracle.com/java/17/latest/jdk-17_linux-x64_bin.tar.gz

# 解压
sudo tar -xzf jdk-17_linux-x64_bin.tar.gz
sudo mv jdk-17* jdk-17

# 配置环境变量
sudo tee -a /etc/profile <<EOF
export JAVA_HOME=/opt/jdk-17
export PATH=\$JAVA_HOME/bin:\$PATH
EOF

# 使环境变量生效
source /etc/profile

# 验证安装
java -version
```

### Ubuntu 安装命令

```bash
sudo apt update
sudo apt install -y openjdk-17-jdk
java -version
```

## 安装 MySQL 8.0

### 1. 添加 MySQL 官方仓库

```bash
# 下载 MySQL 仓库配置
sudo wget https://dev.mysql.com/get/mysql80-community-release-el7-7.noarch.rpm

# 安装仓库配置
sudo rpm -ivh mysql80-community-release-el7-7.noarch.rpm

# 更新 yum 缓存
sudo yum clean all
sudo yum makecache
```

### 2. 安装 MySQL

```bash
# 安装 MySQL 8.0
sudo yum install -y mysql-community-server

# 启动 MySQL
sudo systemctl start mysqld

# 设置开机自启
sudo systemctl enable mysqld

# 查看状态
sudo systemctl status mysqld
```

### 3. 获取临时密码

```bash
sudo grep 'temporary password' /var/log/mysqld.log
```

**输出示例：**
```
2024-02-15T10:00:00.123456Z 6 [Note] A temporary password is generated for root@localhost: Abc123!@#Xyz
```

临时密码：`Abc123!@#Xyz`

### 4. 修改 root 密码

```bash
# 登录 MySQL
mysql -u root -p
# 输入临时密码

# 修改密码（密码必须包含大小写字母、数字、特殊字符，长度至少8位）
ALTER USER 'root'@'localhost' IDENTIFIED BY 'YourNewPassword123!';

# 刷新权限
FLUSH PRIVILEGES;

# 退出
exit;
```

### 5. 创建数据库和用户

```bash
# 登录 MySQL
mysql -u root -p

# 创建数据库
CREATE DATABASE hk_electronics CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 创建用户（允许远程连接）
CREATE USER 'huakang'@'%' IDENTIFIED BY 'HuaKang2024!';

# 授权
GRANT ALL PRIVILEGES ON hk_electronics.* TO 'huakang'@'%';

# 刷新权限
FLUSH PRIVILEGES;

# 退出
exit;
```

### 6. 配置 MySQL（可选优化）

```bash
# 编辑配置文件
sudo vi /etc/my.cnf
```

**添加以下配置：**
```ini
[mysqld]
# 字符集
character-set-server=utf8mb4
collation-server=utf8mb4_unicode_ci

# 时区
default-time-zone='+8:00'

# 最大连接数
max_connections=500

# 慢查询日志
slow_query_log=1
slow_query_log_file=/var/log/mysql/slow.log
long_query_time=2

# 二进制日志（可选，用于主从复制）
# log-bin=mysql-bin
# server-id=1
```

**重启 MySQL：**
```bash
sudo systemctl restart mysqld
```

### 7. 导入数据库

```bash
# 上传 SQL 文件到服务器（在本地执行）
scp database_init_enterprise.sql root@123.456.789.100:/tmp/

# 在服务器上导入
mysql -u huakang -p hk_electronics < /tmp/database_init_enterprise.sql
```

### Ubuntu 安装命令

```bash
sudo apt update
sudo apt install -y mysql-server
sudo systemctl start mysql
sudo systemctl enable mysql
sudo mysql_secure_installation
```

## 安装 Redis

### 1. 安装 Redis

```bash
# 安装 EPEL 仓库
sudo yum install -y epel-release

# 安装 Redis
sudo yum install -y redis

# 启动 Redis
sudo systemctl start redis

# 设置开机自启
sudo systemctl enable redis

# 查看状态
sudo systemctl status redis
```

### 2. 配置 Redis

```bash
# 编辑配置文件
sudo vi /etc/redis.conf
```

**修改以下配置：**
```ini
# 绑定地址（允许远程连接，生产环境建议只允许内网）
bind 0.0.0.0

# 保护模式（关闭后允许远程连接）
protected-mode no

# 设置密码（强烈推荐）
requirepass YourRedisPassword123!

# 持久化配置
save 900 1
save 300 10
save 60 10000

# 最大内存（根据服务器配置调整）
maxmemory 1gb
maxmemory-policy allkeys-lru
```

**重启 Redis：**
```bash
sudo systemctl restart redis
```

### 3. 测试连接

```bash
# 本地连接
redis-cli -a YourRedisPassword123!

# 测试命令
127.0.0.1:6379> ping
PONG

127.0.0.1:6379> set test "hello"
OK

127.0.0.1:6379> get test
"hello"

127.0.0.1:6379> exit
```

### Ubuntu 安装命令

```bash
sudo apt update
sudo apt install -y redis-server
sudo systemctl start redis
sudo systemctl enable redis
```

## 配置防火墙

### 1. CentOS 7 防火墙（firewalld）

```bash
# 启动防火墙
sudo systemctl start firewalld
sudo systemctl enable firewalld

# 开放端口
sudo firewall-cmd --permanent --add-port=80/tcp      # HTTP
sudo firewall-cmd --permanent --add-port=443/tcp     # HTTPS
sudo firewall-cmd --permanent --add-port=8080/tcp    # 后端服务
sudo firewall-cmd --permanent --add-port=3306/tcp    # MySQL（可选，建议只允许内网）
sudo firewall-cmd --permanent --add-port=6379/tcp    # Redis（可选，建议只允许内网）

# 重载防火墙
sudo firewall-cmd --reload

# 查看开放的端口
sudo firewall-cmd --list-ports
```

### 2. Ubuntu 防火墙（ufw）

```bash
# 启用防火墙
sudo ufw enable

# 开放端口
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 8080/tcp

# 查看状态
sudo ufw status
```

### 3. 云服务器安全组

**重要：除了服务器防火墙，还需要在云服务商控制台配置安全组规则。**

**阿里云安全组配置：**
1. 进入 ECS 控制台
2. 选择实例 → 安全组 → 配置规则
3. 添加入方向规则：
   - 端口：80/443/8080
   - 授权对象：0.0.0.0/0
   - 协议：TCP

## 常见问题

### Q1: MySQL 无法远程连接

**解决方案：**
1. 检查防火墙是否开放 3306 端口
2. 检查 MySQL 用户是否允许远程连接（`'user'@'%'`）
3. 检查云服务器安全组是否开放 3306 端口

### Q2: Redis 无法远程连接

**解决方案：**
1. 检查 `redis.conf` 中的 `bind` 配置
2. 检查 `protected-mode` 是否关闭
3. 检查防火墙和安全组

### Q3: Nginx 无法访问

**解决方案：**
1. 检查 Nginx 是否启动：`sudo systemctl status nginx`
2. 检查防火墙是否开放 80 端口
3. 检查云服务器安全组
