## 准备工作

### 1. 确认环境已准备

确保已完成以下步骤：
- ✅ 阿里云 OSS 已配置（参考 [1-OSS配置指南.md](./1-OSS配置指南.md)）
- ✅ 服务器环境已准备（参考 [2-服务器环境准备.md](./2-服务器环境准备.md)）
- ✅ MySQL 数据库已创建并导入数据
- ✅ Redis 已安装并配置密码

### 2. 创建部署目录

```bash
# 在服务器上创建目录
sudo mkdir -p /opt/huakang
sudo mkdir -p /opt/huakang/logs
sudo mkdir -p /opt/huakang/config

# 修改目录权限
sudo chown -R deploy:deploy /opt/huakang
```

## 打包项目

### 1. 修改配置文件

在本地修改 `application.yml`，确保生产环境配置正确：

**backend/huakang-admin/src/main/resources/application.yml**

```yaml
spring:
  profiles:
    active: prod  # 修改为 prod
```

### 2. 打包项目

```bash
# 在项目根目录执行
cd backend

# 清理并打包（跳过测试）
mvn clean package -DskipTests

# 或者只打包 admin 模块
cd huakang-admin
mvn clean package -DskipTests
```

**打包成功后，JAR 文件位置：**
```
backend/huakang-admin/target/huakang-admin-1.0.0.jar
```

### 3. 验证 JAR 包

```bash
# 查看 JAR 包大小
ls -lh backend/huakang-admin/target/huakang-admin-1.0.0.jar

# 预期大小：50-80MB
```

## 上传到服务器

### 方式1：使用 SCP 上传

```bash
# 在本地执行（Windows PowerShell 或 Mac/Linux 终端）
scp backend/huakang-admin/target/huakang-admin-1.0.0.jar root@123.456.789.100:/opt/huakang/
```

### 方式2：使用 FTP 工具

推荐工具：
- **FileZilla**（跨平台）
- **WinSCP**（Windows）
- **Transmit**（Mac）

**连接信息：**
- 协议：SFTP
- 主机：123.456.789.100
- 端口：22
- 用户名：root
- 密码：your_password

**上传文件：**
- 本地路径：`backend/huakang-admin/target/huakang-admin-1.0.0.jar`
- 远程路径：`/opt/huakang/huakang-admin-1.0.0.jar`

### 方式3：使用 Git 拉取代码并在服务器上打包

```bash
# 在服务器上执行
cd /opt/huakang

# 克隆代码
git clone https://gitee.com/sywqorz/huakang-e-commerce-system.git
cd huakang-e-commerce-system

# 切换到 dev 分支
git checkout dev

# 打包
cd backend/huakang-admin
mvn clean package -DskipTests

# 复制 JAR 包
cp target/huakang-admin-1.0.0.jar /opt/huakang/
```

## 启动项目

### 方式1：直接启动（测试用）

```bash
# 加载环境变量并启动
cd /opt/huakang
export $(cat .env | xargs)
java -jar huakang-admin-1.0.0.jar --spring.profiles.active=prod
```

**查看启动日志：**
- 如果看到 `Started HuakangAdminApplication in X seconds`，说明启动成功
- 访问：`http://123.456.789.100:8080/api/admin/health`
- 应该返回：`{"status":"UP"}`

### 方式2：后台启动（推荐）

```bash
# 创建启动脚本
vi /opt/huakang/start.sh
```

**添加以下内容：**

```bash
#!/bin/bash

# 加载环境变量
export $(cat /opt/huakang/.env | xargs)

# 启动参数
APP_NAME="huakang-admin"
JAR_FILE="/opt/huakang/huakang-admin-1.0.0.jar"
LOG_FILE="/opt/huakang/logs/application.log"
PID_FILE="/opt/huakang/${APP_NAME}.pid"

# JVM参数
JVM_OPTS="-Xms512m -Xmx1024m -XX:+UseG1GC -XX:MaxGCPauseMillis=200"

# Spring参数
SPRING_OPTS="--spring.profiles.active=prod"

# 检查是否已启动
if [ -f "$PID_FILE" ]; then
    PID=$(cat $PID_FILE)
    if ps -p $PID > /dev/null 2>&1; then
        echo "$APP_NAME is already running (PID: $PID)"
        exit 1
    fi
fi

# 启动应用
echo "Starting $APP_NAME..."
nohup java $JVM_OPTS -jar $JAR_FILE $SPRING_OPTS > $LOG_FILE 2>&1 &

# 保存PID
echo $! > $PID_FILE

echo "$APP_NAME started successfully (PID: $(cat $PID_FILE))"
echo "Log file: $LOG_FILE"
```

**创建停止脚本：**

```bash
vi /opt/huakang/stop.sh
```

**添加以下内容：**

```bash
#!/bin/bash

APP_NAME="huakang-admin"
PID_FILE="/opt/huakang/${APP_NAME}.pid"

if [ ! -f "$PID_FILE" ]; then
    echo "$APP_NAME is not running"
    exit 1
fi

PID=$(cat $PID_FILE)

if ! ps -p $PID > /dev/null 2>&1; then
    echo "$APP_NAME is not running"
    rm -f $PID_FILE
    exit 1
fi

echo "Stopping $APP_NAME (PID: $PID)..."
kill $PID

# 等待进程结束
for i in {1..30}; do
    if ! ps -p $PID > /dev/null 2>&1; then
        echo "$APP_NAME stopped successfully"
        rm -f $PID_FILE
        exit 0
    fi
    sleep 1
done

# 强制结束
echo "Force stopping $APP_NAME..."
kill -9 $PID
rm -f $PID_FILE
echo "$APP_NAME stopped"
```

**创建重启脚本：**

```bash
vi /opt/huakang/restart.sh
```

**添加以下内容：**

```bash
#!/bin/bash

cd /opt/huakang
./stop.sh
sleep 2
./start.sh
```

**设置脚本权限：**

```bash
chmod +x /opt/huakang/start.sh
chmod +x /opt/huakang/stop.sh
chmod +x /opt/huakang/restart.sh
```

**启动项目：**

```bash
cd /opt/huakang
./start.sh
```

**查看日志：**

```bash
tail -f /opt/huakang/logs/application.log
```

## 配置开机自启

### 方式1：使用 systemd（推荐）

```bash
# 创建 systemd 服务文件
sudo vi /etc/systemd/system/huakang-admin.service
```

**添加以下内容：**

```ini
[Unit]
Description=Huakang Electronics Admin Service
After=network.target mysql.service redis.service

[Service]
Type=simple
User=deploy
WorkingDirectory=/opt/huakang
EnvironmentFile=/opt/huakang/.env
ExecStart=/usr/bin/java -Xms512m -Xmx1024m -XX:+UseG1GC -jar /opt/huakang/huakang-admin-1.0.0.jar --spring.profiles.active=prod
ExecStop=/bin/kill -15 $MAINPID
Restart=on-failure
RestartSec=10
StandardOutput=append:/opt/huakang/logs/application.log
StandardError=append:/opt/huakang/logs/error.log

[Install]
WantedBy=multi-user.target
```

**启用服务：**

```bash
# 重载 systemd 配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start huakang-admin

# 设置开机自启
sudo systemctl enable huakang-admin

# 查看状态
sudo systemctl status huakang-admin
```

**常用命令：**

```bash
# 启动
sudo systemctl start huakang-admin

# 停止
sudo systemctl stop huakang-admin

# 重启
sudo systemctl restart huakang-admin

# 查看状态
sudo systemctl status huakang-admin

# 查看日志
sudo journalctl -u huakang-admin -f
```

## 日志管理

### 1. 日志文件位置

```
应用日志：/opt/huakang/logs/application.log
错误日志：/opt/huakang/logs/error.log
Spring Boot日志：/opt/huakang/logs/huakang-admin-prod.log
```

### 2. 查看日志

```bash
# 实时查看日志
tail -f /opt/huakang/logs/application.log

# 查看最后100行
tail -n 100 /opt/huakang/logs/application.log

# 搜索错误日志
grep -i error /opt/huakang/logs/application.log

# 查看今天的日志
grep "$(date +%Y-%m-%d)" /opt/huakang/logs/application.log
```

### 3. 日志轮转（防止日志文件过大）

```bash
# 创建 logrotate 配置
sudo vi /etc/logrotate.d/huakang-admin
```

**添加以下内容：**

```
/opt/huakang/logs/*.log {
    daily
    rotate 30
    missingok
    notifempty
    compress
    delaycompress
    copytruncate
    dateext
    dateformat -%Y%m%d
}
```

**说明：**
- `daily`：每天轮转一次
- `rotate 30`：保留30天的日志
- `compress`：压缩旧日志
- `copytruncate`：复制后清空原文件（不影响正在写入的进程）

## 常见问题

### Q1: 启动失败，提示"端口已被占用"

**解决方案：**

```bash
# 查看8080端口占用情况
sudo netstat -tlnp | grep 8080

# 或使用 lsof
sudo lsof -i:8080

# 结束占用端口的进程
sudo kill -9 <PID>
```

### Q2: 启动失败，提示"无法连接数据库"

**解决方案：**

1. 检查 MySQL 是否启动：
```bash
sudo systemctl status mysqld
```

2. 检查数据库连接信息是否正确：
```bash
mysql -h localhost -P 3306 -u huakang -p hk_electronics
```

3. 检查防火墙是否阻止连接

### Q3: 启动失败，提示"无法连接 Redis"

**解决方案：**

1. 检查 Redis 是否启动：
```bash
sudo systemctl status redis
```

2. 测试 Redis 连接：
```bash
redis-cli -h localhost -p 6379 -a YourRedisPassword123! ping
```

### Q4: OSS 上传失败

**解决方案：**

1. 检查 OSS 配置是否正确
2. 检查 AccessKey 是否有效
3. 检查服务器是否能访问 OSS：
```bash
curl -I https://oss-cn-hangzhou.aliyuncs.com
```

### Q5: 内存不足，启动失败

**解决方案：**

调整 JVM 参数，减少内存占用：

```bash
# 修改启动脚本中的 JVM_OPTS
JVM_OPTS="-Xms256m -Xmx512m -XX:+UseG1GC"
```

### Q6: 如何查看应用是否正常运行？

```bash
# 方式1：检查进程
ps aux | grep huakang-admin

# 方式2：检查端口
sudo netstat -tlnp | grep 8080

# 方式3：访问健康检查接口
curl http://localhost:8080/api/admin/health

# 方式4：查看日志
tail -f /opt/huakang/logs/application.log
```
