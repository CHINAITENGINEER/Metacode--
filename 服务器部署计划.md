## 🐳 Docker部署方案（推荐）

### 1. 创建Dockerfile

创建 `backend/Dockerfile`：

```dockerfile
# 多阶段构建
FROM maven:3.9-eclipse-temurin-21 AS builder

WORKDIR /app

# 复制pom文件
COPY pom.xml .
COPY huakang-common/pom.xml huakang-common/
COPY huakang-mapper/pom.xml huakang-mapper/
COPY huakang-service/pom.xml huakang-service/
COPY huakang-admin/pom.xml huakang-admin/
COPY huakang-miniapp/pom.xml huakang-miniapp/

# 下载依赖
RUN mvn dependency:go-offline -B

# 复制源代码
COPY huakang-common huakang-common/
COPY huakang-mapper huakang-mapper/
COPY huakang-service huakang-service/
COPY huakang-admin huakang-admin/
COPY huakang-miniapp huakang-miniapp/

# 编译打包
RUN mvn clean package -DskipTests -B

# 运行阶段
FROM eclipse-temurin:21-jre-alpine

WORKDIR /app

# 安装时区数据
RUN apk add --no-cache tzdata && \
    cp /usr/share/zoneinfo/Asia/Shanghai /etc/localtime && \
    echo "Asia/Shanghai" > /etc/timezone && \
    apk del tzdata

# 复制jar包
COPY --from=builder /app/huakang-admin/target/huakang-admin-*.jar app-admin.jar
COPY --from=builder /app/huakang-miniapp/target/huakang-miniapp-*.jar app-miniapp.jar

# 创建日志目录
RUN mkdir -p /app/logs

# 健康检查
HEALTHCHECK --interval=30s --timeout=3s --start-period=60s --retries=3 \
  CMD wget --no-verbose --tries=1 --spider http://localhost:8080/actuator/health || exit 1

# 暴露端口
EXPOSE 8080 8081

# 启动脚本
COPY docker-entrypoint.sh /
RUN chmod +x /docker-entrypoint.sh

ENTRYPOINT ["/docker-entrypoint.sh"]
```

### 2. 创建启动脚本

创建 `backend/docker-entrypoint.sh`：

```bash
#!/bin/sh

# 启动Admin服务
if [ "$SERVICE_TYPE" = "admin" ]; then
    echo "Starting Admin Service..."
    exec java -jar \
        -Xms512m -Xmx1024m \
        -Dspring.profiles.active=prod \
        -Dfile.encoding=UTF-8 \
        -Duser.timezone=Asia/Shanghai \
        app-admin.jar
fi

# 启动Miniapp服务
if [ "$SERVICE_TYPE" = "miniapp" ]; then
    echo "Starting Miniapp Service..."
    exec java -jar \
        -Xms512m -Xmx1024m \
        -Dspring.profiles.active=prod \
        -Dfile.encoding=UTF-8 \
        -Duser.timezone=Asia/Shanghai \
        app-miniapp.jar
fi

echo "Error: SERVICE_TYPE not set"
exit 1
```

## 📦 传统部署方案

### 1. 安装Java 21

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install openjdk-21-jdk -y

# CentOS/RHEL
sudo yum install java-21-openjdk-devel -y

# 验证安装
java -version
```

### 2. 安装MySQL 8.0

```bash
# Ubuntu/Debian
sudo apt install mysql-server-8.0 -y

# 启动MySQL
sudo systemctl start mysql
sudo systemctl enable mysql

# 安全配置
sudo mysql_secure_installation

# 创建数据库和用户
mysql -u root -p << EOF
CREATE DATABASE hk_electronics CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'hk_prod'@'localhost' IDENTIFIED BY '<生成的密码>';
GRANT ALL PRIVILEGES ON hk_electronics.* TO 'hk_prod'@'localhost';
FLUSH PRIVILEGES;
EOF

# 导入数据
mysql -u hk_prod -p hk_electronics < database_init_enterprise_fixed.sql
```

### 3. 安装Redis 7

```bash
# Ubuntu/Debian
sudo apt install redis-server -y

# 配置Redis密码
sudo nano /etc/redis/redis.conf
# 找到 # requirepass foobared
# 改为 requirepass <生成的Redis密码>

# 重启Redis
sudo systemctl restart redis
sudo systemctl enable redis
```

### 4. 编译项目

```bash
# 进入项目目录
cd /opt/huakang/电器项目-后端/backend

# 编译打包
mvn clean package -DskipTests

# 创建部署目录
sudo mkdir -p /opt/huakang/admin
sudo mkdir -p /opt/huakang/miniapp
sudo mkdir -p /opt/huakang/logs

# 复制jar包
sudo cp huakang-admin/target/huakang-admin-1.0.0.jar /opt/huakang/admin/
sudo cp huakang-miniapp/target/huakang-miniapp-1.0.0.jar /opt/huakang/miniapp/
```

### 5. 创建systemd服务

创建 `/etc/systemd/system/huakang-admin.service`：

```ini
[Unit]
Description=Huakang Admin Service
After=network.target mysql.service redis.service

[Service]
Type=simple
User=huakang
WorkingDirectory=/opt/huakang/admin
ExecStart=/usr/bin/java -jar \
    -Xms512m -Xmx1024m \
    -Dspring.profiles.active=prod \
    -Dfile.encoding=UTF-8 \
    -Duser.timezone=Asia/Shanghai \
    huakang-admin-1.0.0.jar
Restart=always
RestartSec=10
StandardOutput=append:/opt/huakang/logs/admin-stdout.log
StandardError=append:/opt/huakang/logs/admin-stderr.log

Environment="DB_HOST=localhost"
Environment="DB_PORT=3306"
Environment="DB_NAME=hk_electronics"
Environment="DB_USERNAME=hk_prod"
Environment="DB_PASSWORD=<数据库密码>"
Environment="REDIS_HOST=localhost"
Environment="REDIS_PORT=6379"
Environment="REDIS_PASSWORD=<Redis密码>"
Environment="JWT_SECRET=<JWT密钥>"

[Install]
WantedBy=multi-user.target
```

创建 `/etc/systemd/system/huakang-miniapp.service`（类似配置）

### 6. 启动服务

```bash
# 重载systemd
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start huakang-admin
sudo systemctl start huakang-miniapp

# 设置开机自启
sudo systemctl enable huakang-admin
sudo systemctl enable huakang-miniapp

# 查看状态
sudo systemctl status huakang-admin
sudo systemctl status huakang-miniapp

# 查看日志
sudo journalctl -u huakang-admin -f
```

## 🌐 Nginx配置

### 1. 安装Nginx

```bash
# Ubuntu/Debian
sudo apt install nginx -y

# 启动Nginx
sudo systemctl start nginx
sudo systemctl enable nginx
```

### 2. 配置反向代理

创建 `/etc/nginx/sites-available/huakang`：

```nginx
# Admin后台管理
server {
    listen 80;
    server_name admin.yourdomain.com;

    # 重定向到HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name admin.yourdomain.com;

    # SSL证书配置
    ssl_certificate /etc/nginx/ssl/admin.yourdomain.com.crt;
    ssl_certificate_key /etc/nginx/ssl/admin.yourdomain.com.key;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # 日志
    access_log /var/log/nginx/admin-access.log;
    error_log /var/log/nginx/admin-error.log;

    # 反向代理
    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 文件上传大小限制
    client_max_body_size 50m;
}

# Miniapp小程序端
server {
    listen 80;
    server_name api.yourdomain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.yourdomain.com;

    ssl_certificate /etc/nginx/ssl/api.yourdomain.com.crt;
    ssl_certificate_key /etc/nginx/ssl/api.yourdomain.com.key;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    access_log /var/log/nginx/miniapp-access.log;
    error_log /var/log/nginx/miniapp-error.log;

    location / {
        proxy_pass http://localhost:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    client_max_body_size 10m;
}
```

### 3. 启用配置

```bash
# 创建软链接
sudo ln -s /etc/nginx/sites-available/huakang /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重载Nginx
sudo systemctl reload nginx
```

## 💾 备份方案

### 1. 数据库备份脚本

创建 `/opt/huakang/scripts/backup-mysql.sh`：

```bash
#!/bin/bash

BACKUP_DIR="/opt/huakang/backups/mysql"
DATE=$(date +%Y%m%d_%H%M%S)
DB_NAME="hk_electronics"
DB_USER="hk_prod"
DB_PASS="<数据库密码>"

mkdir -p $BACKUP_DIR

# 备份数据库
mysqldump -u$DB_USER -p$DB_PASS $DB_NAME | gzip > $BACKUP_DIR/${DB_NAME}_${DATE}.sql.gz

# 删除30天前的备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +30 -delete

echo "Backup completed: ${DB_NAME}_${DATE}.sql.gz"
```

### 2. 设置定时备份

```bash
# 添加到crontab
crontab -e

# 每天凌晨2点备份
0 2 * * * /opt/huakang/scripts/backup-mysql.sh
```
