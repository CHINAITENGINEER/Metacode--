## 🚀 快速启动

### 1. 进入backend目录
```bash
cd backend
```

### 2. 编译项目
```bash
mvn clean install
```

### 3. 启动后台管理API
```bash
cd huakang-admin
mvn spring-boot:run
```

访问：
- 应用：http://localhost:8080/api/admin
- 测试接口：http://localhost:8080/api/admin/test/health
- API文档：http://localhost:8080/api/admin/doc.html

### 4. 启动小程序API
```bash
cd huakang-miniapp
mvn spring-boot:run
```

访问：
- 应用：http://localhost:8081/api/miniapp
- 测试接口：http://localhost:8081/api/miniapp/test/health
- API文档：http://localhost:8081/api/miniapp/doc.html

## ⚠️ 注意事项

### 1. 数据库配置
修改 `application.yml` 中的数据库连接信息：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/hk_electronics
    username: root
    password: root
```

### 2. Redis配置
确保Redis已启动，默认连接 `localhost:6379`

### 3. 数据库初始化
执行数据库初始化脚本（在项目根目录）：
```bash
mysql -u root -p < ../database_init_enterprise.sql
mysql -u root -p < ../index_optimization.sql
```
