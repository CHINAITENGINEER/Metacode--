## 🎯 模块职责说明

### huakang-common（公共模块）
- **职责：** 提供公共类、工具类、常量等
- **依赖：** 无（最底层）
- **包含：**
  - 统一响应结果（Result、PageResult）
  - 异常处理（BusinessException、GlobalExceptionHandler）
  - 工具类、常量

### huakang-mapper（数据访问层）
- **职责：** 数据库访问相关
- **依赖：** huakang-common
- **包含：**
  - 实体类（Entity）
  - Mapper接口
  - MyBatis配置

### huakang-service（业务服务层）
- **职责：** 业务逻辑实现
- **依赖：** huakang-mapper
- **包含：**
  - Service接口和实现
  - Redis配置
  - JWT工具类
  - 业务逻辑

### huakang-admin（后台管理API）
- **职责：** 后台管理接口
- **依赖：** huakang-service
- **包含：**
  - Controller
  - DTO/VO
  - Spring Security配置
  - API文档配置

### huakang-miniapp（小程序API）
- **职责：** 小程序接口
- **依赖：** huakang-service
- **包含：**
  - Controller
  - DTO/VO
  - API文档配置

## 📝 开发规范

### 1. 包命名规范
- `entity` - 实体类
- `mapper` - Mapper接口
- `service` - Service接口
- `impl` - Service实现
- `controller` - Controller
- `dto` - 数据传输对象（请求）
- `vo` - 视图对象（响应）
- `config` - 配置类
- `utils` - 工具类
- `constants` - 常量

### 2. 类命名规范
- Entity：实体名（如 `Member`）
- Mapper：实体名 + Mapper（如 `MemberMapper`）
- Service：实体名 + Service（如 `MemberService`）
- ServiceImpl：实体名 + ServiceImpl（如 `MemberServiceImpl`）
- Controller：实体名 + Controller（如 `MemberController`）
- DTO：功能名 + DTO（如 `LoginDTO`）
- VO：实体名 + VO（如 `MemberVO`）

### 3. 接口路径规范
- 后台管理：`/api/admin/模块/功能`
- 小程序：`/api/miniapp/模块/功能`

### 4. 统一响应格式
```java
// 成功响应
Result.success(data)
Result.success("操作成功", data)

// 失败响应
Result.error("错误信息")
Result.error(ResultCode.BUSINESS_ERROR)
```
