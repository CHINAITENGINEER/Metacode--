## 🎯 模块职责说明

### huakang-common（公共模块）
- **职责：** 提供公共类、工具类、常量等
- **依赖：** 无（最底层）
- **包含：**
  - 统一响应结果（Result、PageResult）
  - 异常处理（BusinessException、GlobalExceptionHandler）
  - 工具类、常量

### huakang-mapper（数据访问层）
- **职责：** 数据库访问相关
- **依赖：** huakang-common
- **包含：**
  - 实体类（Entity）
  - Mapper接口
  - MyBatis配置

### huakang-service（业务服务层）
- **职责：** 业务逻辑实现
- **依赖：** huakang-mapper
- **包含：**
  - Service接口和实现
  - Redis配置
  - JWT工具类
  - 业务逻辑
  - 数据传输对象（DTO）
  - 定时任务

### huakang-admin（后台管理API）
- **职责：** 后台管理接口
- **依赖：** huakang-service
- **包含：**
  - Controller
  - DTO/VO
  - Spring Security配置
  - JWT认证过滤器
  - API文档配置

### huakang-miniapp（小程序API）
- **职责：** 小程序接口
- **依赖：** huakang-service
- **包含：**
  - Controller
  - API文档配置

## 📱 小程序模块详细说明

### Controller层（huakang-miniapp/controller）
- **WechatAuthController** - 微信登录认证接口
  - `POST /auth/wechat-login` - 微信登录
- **MiniappProductController** - 商品接口
  - `GET /products` - 商品列表
  - `GET /products/{id}` - 商品详情
  - `GET /products/wechat-qrcode` - 企业微信二维码
- **MiniappMemberController** - 会员接口
  - `GET /members/profile` - 获取会员信息
- **MiniappPointsController** - 积分接口
  - `GET /points-records` - 积分记录列表
- **MiniappSystemConfigController** - 系统配置接口
  - `GET /system-configs/wechat-qrcode` - 获取企业微信二维码
- **TestController** - 测试接口
  - `GET /test/health` - 健康检查
- **ServiceOrderController** - 预留接口

### 业务功能
- **微信登录认证**：通过微信授权码换取用户信息和JWT Token
- **商品展示**：全量商品和积分商品的列表和详情展示
- **会员中心**：获取当前会员信息，包含积分总额
- **积分记录**：查看积分变动历史
- **企业微信咨询**：获取企业微信二维码

## 🔧 核心配置

### Redis配置（huakang-service/config/RedisConfig.java）
- 启用Spring Cache注解
- 配置RedisTemplate
- 配置CacheManager，支持Java 8日期时间类型序列化

### JWT配置
- Token有效期2小时
- 使用HS256算法
- 包含用户ID、用户名、角色等信息

### 数据库配置
- 使用MyBatis-Plus
- 支持逻辑删除
- 支持自动填充创建时间和更新时间

## 📝 开发规范

### 1. 包命名规范
- `entity` - 实体类
- `mapper` - Mapper接口
- `service` - Service接口
- `impl` - Service实现
- `controller` - Controller
- `dto` - 数据传输对象（请求）
- `vo` - 视图对象（响应）
- `config` - 配置类
- `utils` - 工具类
- `constants` - 常量

### 2. 类命名规范
- Entity：实体名（如 `Member`）
- Mapper：实体名 + Mapper（如 `MemberMapper`）
- Service：实体名 + Service（如 `MemberService`）
- ServiceImpl：实体名 + ServiceImpl（如 `MemberServiceImpl`）
- Controller：实体名 + Controller（如 `MemberController`）
- DTO：功能名 + DTO（如 `LoginDTO`）
- VO：实体名 + VO（如 `MemberVO`）

### 3. 接口路径规范
- 后台管理：`/api/admin/模块/功能`
- 小程序：`/api/miniapp/模块/功能`

### 4. 统一响应格式
```java
// 成功响应
Result.success(data)
Result.success("操作成功", data)

// 失败响应
Result.error("错误信息")
Result.error(ResultCode.BUSINESS_ERROR)
```

### 5. 异常处理
- 全局异常处理（GlobalExceptionHandler）
- 业务异常（BusinessException）
- 统一错误码管理（ResultCode）

### 6. 缓存使用
- 使用Spring Cache注解
- 缓存命名规范：`模块名:功能:参数`格式
- 合理设置缓存过期时间

## 🚀 接口开发说明

### 小程序接口文档
专门的小程序前端接口文档请参考：`小程序模块前端接口文档.md`

### 前后端对接注意事项
1. 所有需要认证的接口都需要在请求头中包含 `Authorization: Bearer {token}`
2. JWT Token通常在登录后获得，需要在前端存储并在后续请求中携带
3. 分页查询的参数使用 `page` 和 `size`
4. 日期时间格式为ISO 8601格式（如：2024-01-01T10:00:00）
5. 接口返回统一使用Result格式
6. 错误码和消息统一管理
