# 快速开始指南

## 📁 项目结构

所有后端代码已统一放入 `backend/` 目录：

```
backend/
├── pom.xml                    # 父POM文件
├── README.md                  # 项目说明
├── huakang-common/           # 公共模块
├── huakang-mapper/           # 数据访问层
├── huakang-service/          # 业务服务层
├── huakang-admin/            # 后台管理API（端口8080）
└── huakang-miniapp/          # 小程序API（端口8081）
```

## 🚀 快速启动

### 1. 进入backend目录
```bash
cd backend
```

### 2. 编译项目
```bash
mvn clean install
```

### 3. 启动后台管理API
```bash
cd huakang-admin
mvn spring-boot:run
```

访问：
- 应用：http://localhost:8080/api/admin
- 测试接口：http://localhost:8080/api/admin/test/health
- API文档：http://localhost:8080/api/admin/doc.html

### 4. 启动小程序API（新终端）
```bash
cd backend/huakang-miniapp
mvn spring-boot:run
```

访问：
- 应用：http://localhost:8081/api/miniapp
- 测试接口：http://localhost:8081/api/miniapp/test/health
- API文档：http://localhost:8081/api/miniapp/doc.html

## ⚠️ 注意事项

1. **数据库初始化**：在项目根目录执行SQL脚本
2. **Redis启动**：确保Redis已启动（localhost:6379）
3. **pom.xml修复**：如果编译报错，检查pom.xml中的`<n>`标签，应改为`<name>`
