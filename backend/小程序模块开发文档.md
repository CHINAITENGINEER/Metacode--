# 华康电器连锁积分小程序 - 后端开发文档

## 项目概述

华康电器连锁积分小程序后端服务是一个基于Spring Boot 3.1.5 + JDK 21 + MySQL 8.0 + Redis 7.0技术栈的企业级积分管理与商品展示系统。该项目采用模块化架构设计，支持管理员后台管理和微信小程序端服务，主要功能包括：
- 为客户提供便捷的线上商品浏览渠道
- 建立会员积分体系，通过积分商品激励客户，提升客户忠诚度
- 引导客户通过企业微信进行售前咨询，将线上流量引流至私域
- 为管理员和店员提供高效的会员及积分管理后台

目标用户包括：
- C端 (客户)：东莞本地的电器消费者，约 5 万用户规模
- B端 (内部)：公司管理员、一线店员

## 小程序模块功能开发计划

### 1. 微信登录与用户认证模块

#### 1.1 微信登录接口
- **接口路径**: `POST /auth/wechat-login`
- **功能**: 通过微信授权码换取用户信息并创建/更新会员记录
- **逻辑**: 后台根据 OpenID 判断用户是否为新会员
- **请求参数**:
  - `code` (string, required): 微信登录凭证
  - `encryptedData` (string, optional): 加密用户数据
  - `iv` (string, optional): 加密算法的初始向量
- **响应**:
  - `token` (string): JWT访问令牌
  - `memberInfo` (object): 会员信息
  - `isNewUser` (boolean): 是否为新用户

### 2. 全量商品展示模块（首页）

#### 2.1 商品列表接口
- **获取商品列表**: `GET /products`
- **功能**: 作为小程序的主页，采用列表或卡片流形式展示所有在售商品
- **参数**:
  - `type` (integer, default=1): 商品类型 (1=全量商品, 2=积分商品)
  - `page` (integer, default=1): 页码
  - `size` (integer, default=10): 每页数量
  - `status` (integer, optional): 商品状态 (1=上架, 0=下架)
- **响应**:
  - `id`: 商品ID
  - `name`: 商品名称
  - `image`: 商品主图URL
  - `price`: 商品价格
  - `status`: 商品状态

#### 2.2 企业微信二维码接口
- **获取企业微信二维码**: `GET /system-configs/wechat-qrcode`
- **功能**: 获取后台上传的企业微信二维码，用于引导客户咨询

### 3. 积分商城模块

#### 3.1 积分商品列表接口
- **获取积分商品列表**: `GET /products?type=2`
- **功能**: 独立的页面，展示所有可用于积分兑换的商品
- **参数**:
  - `type` (integer, required, value=2): 商品类型 (2=积分商品)
  - `page` (integer, default=1): 页码
  - `size` (integer, default=10): 每页数量
  - `status` (integer, optional): 商品状态 (1=上架, 0=下架)
- **响应**:
  - `id`: 商品ID
  - `name`: 商品名称
  - `image`: 商品主图URL
  - `pointsPrice`: 商品积分价格

### 4. 个人中心模块

#### 4.1 获取会员信息接口
- **获取会员信息**: `GET /members/profile`
- **功能**: 展示会员的个人信息和积分情况
- **响应**:
  - `id`: 会员ID
  - `openid`: 微信OpenID
  - `nickname`: 微信昵称
  - `avatar`: 微信头像URL
  - `totalPoints`: 当前可用积分总额

#### 4.2 积分记录查询接口
- **获取积分记录列表**: `GET /points-records`
- **功能**: 以列表形式展示积分的变动历史
- **参数**:
  - `page` (integer, default=1): 页码
  - `size` (integer, default=10): 每页数量
- **响应**:
  - `changeType`: 变动原因 (如：消费赠送、积分兑换、后台调整)
  - `points`: 变动分值 (如:+100 或 -500)
  - `createdAt`: 变动时间
  - `remark`: 备注信息

## 数据库表结构

### 会员表 (members)
- `id`: 主键ID
- `openid`: 微信OpenID
- `nickname`: 微信昵称
- `avatar`: 微信头像URL
- `phone`: 手机号
- `total_points`: 当前积分总额
- `is_deleted`: 是否删除
- `created_at`: 创建时间
- `updated_at`: 更新时间

### 商品表 (products)
- `id`: 主键ID
- `name`: 商品名称
- `image`: 商品主图URL
- `detail_images`: 商品详情图（JSON数组）
- `category`: 商品分类
- `type`: 商品类型（1=全量商品，2=积分商品）
- `price`: 商品价格
- `points_price`: 积分价格
- `description`: 商品描述
- `status`: 状态（1=上架，0=下架）
- `sort_order`: 排序权重

### 积分记录表 (points_records)
- `id`: 主键ID
- `member_id`: 会员ID
- `change_type`: 变动类型
- `points`: 变动分值
- `balance_before`: 变动前积分余额
- `balance_after`: 变动后积分余额
- `business_no`: 业务单号
- `product_id`: 关联商品ID
- `operator_type`: 操作人类型
- `operator_id`: 操作人ID
- `operator_name`: 操作人姓名
- `remark`: 备注
- `ip_address`: 操作IP地址
- `user_agent`: 用户代理
- `created_at`: 创建时间

## JWT认证配置

- **Token有效期**: 2小时（可配置）
- **Token格式**: Bearer Token
- **认证流程**:
  1. 微信登录获取code
  2. 后端使用code换取openid
  3. 根据OpenID判断是否为新会员
  4. 创建/更新会员记录
  5. 生成JWT Token返回

- 使用JWT进行无状态身份验证
- 微信登录时验证code的安全性
- 参数校验防止注入攻击

- 企业微信二维码通过系统配置管理，防止泄露
