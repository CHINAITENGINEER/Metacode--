# 华康电器连锁积分小程序 - 小程序模块前端接口文档

## 接口概览

本接口文档专门针对华康电器连锁积分小程序的前端接口，涵盖微信登录、商品展示、会员信息、积分记录等功能。

### 基础信息
- **接口域名**: `http://localhost:8083` (开发环境) / `https://your-domain.com` (生产环境)
- **接口前缀**: `/api/miniapp`
- **请求头**: `Content-Type: application/json`
- **认证方式**: JWT Bearer Token
- **响应格式**: 统一使用Result格式

### 统一响应格式
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

### 响应码说明
- `200`: 操作成功
- `400`: 参数错误
- `401`: 未授权，请先登录
- `403`: 无权限访问
- `404`: 资源不存在
- `500`: 操作失败

### 2. 商品模块接口

#### 2.1 商品列表
- **接口**: `GET /api/miniapp/products`
- **描述**: 获取商品列表，支持分类、类型筛选
- **请求参数**:
  - `type` (integer): 商品类型 (1=全量商品, 2=积分商品, 默认1)
  - `category` (string): 商品分类
  - `name` (string): 商品名称(模糊查询)
  - `status` (integer): 状态 (1=上架, 0=下架, 默认1)
  - `page` (integer): 页码 (默认1)
  - `size` (integer): 每页数量 (默认10)
- **响应示例**:
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "total": 100,
    "pages": 10,
    "current": 1,
    "size": 10,
    "records": [
      {
        "id": 1,
        "name": "商品名称",
        "image": "商品主图URL",
        "detailImages": ["详情图1", "详情图2"],
        "category": "分类",
        "type": 1,
        "price": 99.99,
        "pointsPrice": 1000,
        "description": "商品描述",
        "status": 1,
        "sortOrder": 0,
        "createdAt": "2024-01-01T10:00:00",
        "updatedAt": "2024-01-01T10:00:00"
      }
    ]
  }
}
```

## 前端使用示例

### 发起请求示例 (JavaScript fetch)
```javascript
// 微信登录请求
fetch('/api/miniapp/auth/wechat-login', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    code: 'your-wechat-code'
  })
})
.then(response => response.json())
.then(data => {
  if (data.code === 200) {
    // 登录成功，获取token
    const token = data.data.token;
    localStorage.setItem('token', token);
  }
});

// 需要认证的请求
const token = localStorage.getItem('token');
fetch('/api/miniapp/members/profile', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${token}`,
    'Content-Type': 'application/json'
  }
})
.then(response => response.json())
.then(data => {
  console.log(data.data);
});
```

## 注意事项

1. 所有需要认证的接口都需要在请求头中包含 `Authorization: Bearer {token}`
2. JWT Token通常在登录后获得，需要在前端存储并在后续请求中携带
3. 分页查询的参数使用 `page` 和 `size`
4. 商品类型：1=全量商品，2=积分商品
5. 返回的分页数据格式保持一致，包含 `total`、`pages`、`current`、`size`、`records`
6. 日期时间格式为ISO 8601格式（如：2024-01-01T10:00:00）
